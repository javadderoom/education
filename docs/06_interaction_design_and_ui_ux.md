# ۶. مهندسی تعامل و نمایش سوالات (UI/UX و ارگونومی شناختی برای تمام رده‌های سنی)

یک خطای رایج در سیستم‌های آموزشی، محدود کردن نمایش سوال به فرم‌های خشک HTML با دکمه‌های رادیویی ریز است. نحوه نمایش سوال و تعامل کاربر با آن، مستقیماً بر میزان درگیری شناختی (Cognitive Engagement) و پایایی نتایج تشخیصی تأثیرگذار است. این سند به مهندسی فرانت‌اند، الگوهای تعاملی و ارگونومی نمایش سوالات برای طیف‌های سنی مختلف می‌پردازد.

---

## ۱. الگوی بنیادین نمایش: کارت‌های میکرو-تعاملی (Micro-Card Carousel Pattern)

نمایش لیست طویل سوالات در یک صفحه عمودی (مانند آزمون‌های سنتی گوگل فرمز یا LMSها) بار شناختی شدیدی ایجاد می‌کند و کاربر را دچار وحشت از حجم کار پیش‌رو (Page Fatigue) می‌سازد.
* **راهکار معماری:** نمایش «یک سوال در هر لحظه (Single-Item Focus)».
* سوال در یک کارت مرکزی شناور با ترنزیشن‌های انیمیشنی روان (در ۶۰ فریم بر ثانیه) نمایش داده می‌شود.
* نوار پیشرفت بالا به جای نمایش درصد استرس‌زا، به شکل یک مسیر مأموریت با نشانه‌های بصری پیش می‌رود.

```
+-----------------------------------------------------------+
|  [گام ۳ از ۵]  ===========>---------------  [راهنما / صدا] |
+-----------------------------------------------------------+
|                                                           |
|    +-------------------------------------------------+    |
|    |  [آیکون بلندگو] متن سوال با فونت درشت و خوانا    |    |
|    |                                                 |    |
|    |       [بخش مدیا: تصویر مفهومی / نمودار / فرمول]     |    |
|    |                                                 |    |
|    |    +--------------------+  +--------------------+   |    |
|    |    |   گزینه الف        |  |   گزینه ب          |   |    |
|    |    +--------------------+  +--------------------+   |    |
|    |    +--------------------+  +--------------------+   |    |
|    |    |   گزینه ج          |  |   گزینه د          |   |    |
|    |    +--------------------+  +--------------------+   |    |
|    +-------------------------------------------------+    |
|                                                           |
|  [تخته چرک‌نویس تعبیه‌شده]                     [رد کردن با شجاعت] |
+-----------------------------------------------------------+
```

## ۲. طراحی تعامل تفکیک‌شده بر اساس رده‌های سنی

### ۲.۱. دبستان (پایه‌های ۱ تا ۳ - کودکان ۶ تا ۸ سال)
* **چالش ارگونومیک:** مهارت‌های حرکتی ظریف (Fine Motor Skills) هنوز کامل نشده، روخوانی کلمات کند است و کار با کیبورد اصطکاک غیرقابل تحملی دارد.
* **الگوهای تعاملی اختصاصی:**
  1. **موتور روخوانی صوتی خودکار (Speech-First / TTS):** با لمس آیکون بلندگو (یا به صورت خودکار در آغاز سوال)، یک فایل صوتی با لهجه طبیعی فارسی و لحن صمیمی سوال را برای کودک می‌خواند.
  2. **کارت‌های لمسی غول‌پیکر (Giant Touch Targets):** ابعاد گزینه‌ها حداقل ۷۲ در ۷۲ پیکسل است تا کودک با انگشت کوچک خود بدون خطا روی آن ضربه بزند.
  3. **دسته‌بندی کشیدنی (Drag & Drop Buckets):** انتقال میوه‌ها یا شکل‌ها به داخل سبدها با انیمیشن فنری (Spring Physics).
  4. **انتخاب بر روی تصویر (Hotspot Tap):** «روی گلدانی که آب کمتری دارد ضربه بزن».

### ۲.۲. دبستان (پایه‌های ۴ تا ۶ - کودکان ۹ تا ۱۱ سال)
* **چالش ارگونومیک:** کودک توانایی روخوانی مستقل دارد اما متن‌های طولانی او را بی‌حوصله می‌کند. ورود به دنیای کسر و اعشار نیازمند تجسم فضایی است.
* **الگوهای تعاملی اختصاصی:**
  1. **ابزار بصری دست‌ورزی کسرها (Interactive Fraction Strips):** امکان دستکاری بصری نوارها برای دیدن هم‌ارزی قبل از انتخاب گزینه نهایی.
  2. **خط‌زن گزینه‌های انحرافی (Elimination Cross-out):** کودک می‌تواند با یک سوایپ سریع روی گزینه‌ای که مطمئن است غلط است، روی آن خط بکشد تا تمرکزش روی گزینه‌های باقی‌مانده بیشتر شود (کاهش بار حافظه فعال).
  3. **اسلایدر محور اعداد (Snap Numberline):** تعیین مکان کسرها روی محور با کشیدن یک نشانگر که روی بخش‌های صحیح قفل می‌شود.

### ۲.۳. متوسطه و داوطلبان کنکور (نوجوانان ۱۲ تا ۱۸ سال)
* **چالش ارگونومیک:** زمان ارزش حیاتی دارد؛ نیاز به تمرکز بالا، شبیه‌سازی فضای رسمی و حل سریع مسائل بدون المان‌های کودکانه.
* **الگوهای تعاملی اختصاصی:**
  1. **آزمون‌های تشخیصی دوسطحی (Two-Tier Diagnostic Modality):**
     * مرحله ۱: انتخاب پاسخ عددی/تحلیلی.
     * بلافاصله در همان کارت بدون رفرش، مرحله ۲ باز می‌شود: *«کدام استدلال زیر پایه انتخاب شما بود؟»* با ۴ گزینه مفهومی جهت تفکیک شانس از درک.
  2. **چرک‌نویس شیشه‌ای (Overlay Canvas Scratchpad):** با زدن یک دکمه شناور، یک لایه نیمه‌شفاف باز می‌شود که دانش‌آموز می‌تواند با قلم نوری یا انگشت محاسبات سرانگشتی را انجام داده و بدون ترک صفحه کارت سوال را حل کند.
  3. **رندرینگ فوق‌سریع فرمول‌های ریاضی و فیزیک با KaTeX فارسی:** نمایش بدون لرزش کدهای LaTeX ریاضی همگام با فونت متن فارسی وزیرمتن (Vazirmatn).

### ۲.۴. آموزش عالی، دانشگاه و متخصصان (بزرگسالان ۱۸+ سال)
* **چالش ارگونومیک:** مطالعه سناریوهای طولانی، مقالات پژوهشی، تداخلات دارویی، تحلیل دیاگرام‌های معماری یا قطعه‌کدهای نرم‌افزاری.
* **الگوهای تعاملی اختصاصی:**
  1. **نمایش اسپلیت دوردیفه/دوستونه (Split-Screen Scenario View):** در یک سمت، متن سناریو، کد برنامه یا نتیجه آزمایش پزشکی قرار دارد و در سمت دیگر گزینه‌های تحلیلی سنجش قرار می‌گیرند.
  2. **هایلایت هوشمند مستندات (Active Doc Inspection):** کاربر می‌تواند برای یافتن سرنخ به متن مرجع ارجاع داده شده مراجعه کند.
  3. **بررسی گزینه‌های چندوجهی (Multi-Select Matrix):** ارزیابی چند مهارت همزمان در قالب یک ماتریس تطبیقی.

## ۳. مهندسی موتور رندرینگ ریاضیات و متون راست‌به‌چپ (Bi-Directional Math)

رندر کردن متون فارسی آمیخته با فرمول‌های ریاضی یکی از بزرگترین چالش‌های فرانت‌اند وب و موبایل است:

```
[جهت راست‌به‌چپ فارسی] ---> کسر مساوی با $ \frac{2x + 1}{3} $ کدام است؟ <--- [جهت چپ‌به‌راست فرمول]
```

### راهکار فنی پیاده‌سازی شده:
1. استفاده از کتابخانه فوق‌العاده سبک و پرسرعت `KaTeX` (با حجم زیر ۳۰۰ کیلوبایت در برابر MathJax سنگین).
2. بسته سفارشی الحاقی CSS برای تنظیم خودکار علائم اعشار و ارقام فارسی در محیط‌های ریاضیاتی دبستان، و سوییچ به ارقام لاتین استاندارد در متون دانشگاهی.
3. استفاده از فونت متغیر متن‌باز `Vazirmatn` که به طور اختصاصی از گلیف‌های ریاضی و علائم فارسی پشتیبانی می‌کند.

## ۴. استراتژی بازخورد روانشناختی: فوری یا تأخیری؟

یک دوراهی مهندسی مهم وجود دارد: آیا بعد از هر سوال جواب را بگوییم یا در انتهای آزمون؟

| حالت آزمون | نوع بازخورد | مناسب برای چه زمانی؟ | اثر روانشناختی |
| :--- | :--- | :--- | :--- |
| **حالت کاوش سازنده (Formative / Exploratory Mode)** | **بازخورد آنی همدلانه (Instant Feedback):** بلافاصله پس از انتخاب، گزینه سبز یا زرد می‌شود و علت انتخاب آن گزینه در یک پاراگراف صمیمی ظاهر می‌گردد. | جلسات تمرینی روزمره، کودکان دبستان، رفع ابهام سریع | ایجاد احساس پیشرفت مداوم، رفع فوری بدفهمی قبل از تثبیت در ذهن |
| **حالت سنجش تشخیصی عیارسنج (Diagnostic Benchmark Mode)** | **بازخورد جامع در پایان (Delayed Comprehensive Report):** در طول ۵ تا ۷ سوال هیچ نتیجه‌ای اعلام نمی‌شود تا سوگیری شناختی ایجاد نشود. | ارزیابی ماهانه، تعیین سطح آغازین، کنکوری‌ها و دانشجویان | جلوگیری از اضطراب لحظه‌ای، شبیه‌سازی فضای واقعی، اندازه‌گیری پارامترهای Slip و Guess بدون نویز ذهنی |

## ۵. دکمه شجاعت: «مطمئن نیستم / این را نخوانده‌ام» (The "I'm Not Sure" Button)

یکی از مخرب‌ترین عوامل در مدل‌های تشخیصی شناختی (DINA و IRT)، **حدس‌های تصادفی کثیف (Random Guessing Noise)** است که پارامتر $g$ را به شدت آلوده می‌کند و سیستم فکر می‌کند دانش‌آموز مهارت را بلد است در حالی که صرفاً خوش‌شانس بوده است!
* **راهکار مهندسی:** تعبیه گزینه‌ای به نام **«مطمئن نیستم / هنوز این را نخوانده‌ام»** در زیر همه سوالات.
* سیستم برای زدن این دکمه پاداش صداقت شناختی (Honesty Streak) در نظر می‌گیرد و با پیام مثبت به کاربر یادآوری می‌کند: *«اعتراف به ندانستن، شجاعانه‌ترین گام برای یادگیریه!»*.
* این دکمه در مدل ریاضی مستقیماً احتمال $g$ را صفر کرده و شاخص نیاز به آموزش را با قطعیت ۱۰۰٪ روی آن مفهوم تنظیم می‌کند.
